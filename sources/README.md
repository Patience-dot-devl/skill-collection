# Sources

Raw exports and evidence, kept as received: search results, API output, saved pages, licence texts
that were checked. Do not edit files here. If a source changes, add the new version beside the old
one with the date in the file name (`YYYY-MM-DD`). The check script skips this folder; material is
checked when it is curated into `docs/`.

Vendored skill code does not belong here. It lives under `skills/` with its upstream licence.
